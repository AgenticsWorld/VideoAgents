闲置时间:每隔该时长巡检一次,流水线空闲(无任务在跑、无待确认项)才发送状态检查消息,默认 5 分钟。阈值:总制片生效引擎(claude/codex)的 5 小时窗口会话用量达到该值时,本轮不发送;用量读取不到时放行。均为全局设置,对所有项目生效(开关在运行面板 🤖 按钮,按项目独立)
防止系统休眠:开启期间,只要任一项目启用了自动运行,就阻止系统因闲置进入睡眠(屏幕照常熄灭;合盖睡眠与手动关机不拦,退出程序自动恢复)。仅支持 macOS/Windows。
常任指令:仅对当前项目生效,自动运行每次唤醒总制片时都随消息附带,总制片会话重开也不丢失;适合放长期约束,建议写成条件式(如「在 ep01-ep10 剧本全部完成前,不派设定类工单」),留空则不附带

⚙️ Agent 高级设置

扇出型 Agent(场景资产、视频生成、审核、验收评分等按场景/组一单的工位)同一 Agent 可同时运行的工单数上限,默认 5。创作型 Agent 为保护会话连续性恒为串行,不受此值影响;全部运行仍受全局 8 个进程槽总闸。每个并发 = 一个真实的模型 CLI 进程,调大会成倍加快额度消耗,网络代理高并发下也更易断连,建议逐步上调。
运行超时:单个工单从启动算起的墙钟上限,默认 120 分钟(总制片要等整条流水线,自动放宽 4 倍),到点连同派生子进程一起终止并记为出错,是回收挂死进程的最后防线。无输出超时:引擎连续多长时间没有任何事件输出即判定挂死并终止,默认 30 分钟,填 0 关闭;比墙钟更早识别 API 长连接不返回、代理断流等假死,又不会误伤跑得慢但在正常干活的长批量任务(总制片大部分时间静默等子任务,不受此项约束)。注意单次工具调用期间引擎不会有事件输出,该值须大于工单里最长的一次工具调用。均为全局设置,保存后对后续启动的工单生效。
Agent 自动重跑/重 roll 的次数上限,默认 1:验收评分、QA 审核或机检不过时,总制片带意见自动退回重做;视频/图像生成机检不达标时自动重 roll。同一任务累计达到该次数仍不过就升级用户裁决,不再自行重试;填 0 则完全不自动重跑,首次不过即升级人工。全局设置,通过运行提示词注入所有 Agent,覆盖流程文档里写死的「最多 3 次」,保存后对后续启动的工单生效。
重跑类确认弹窗(「是否重跑?」等)的等待时长,默认 60 秒:倒计时结束无人答复即自动采用默认选项(通常为「重跑」),流水线不会因等人而卡住。调大可给自己留更多裁决时间,代价是无人值守时流水线在弹窗上等得更久;Agent 显式指定的更短等待仍有效,但不能超过本值。签字类弹窗(H 门人工签字)永不倒计时、永不自动确认,不受本项影响。全局设置,保存后对后续发起的确认生效。
单个工单内引擎的对话轮次上限,默认 250:仅对 claude 与 grok 引擎生效(headless 的 --max-turns 参数,不传则不限,这里主动设闸防失控循环);codex/pi/opencode 引擎无此参数不受影响,deepagents 走框架自身的递归上限。撞上限时引擎会被直接切断且无法续跑,回执只显示退出码 1,已落盘的产物保留但核验与回执缺失——大批量工位(逐组选片、批量切片)一单几十组时 100 轮远远不够,如仍撞限优先调小派单批宽、其次上调本值。全局设置,保存后对后续启动的工单生效。
思考深度(Thinking Effort)统一设置,默认「引擎默认」:派单时按当前引擎翻译成各自的推理强度参数——claude → --effort,codex → model_reasoning_effort(无 max,按 xhigh),pi → --thinking,opencode → --variant(模型没有该档位时被忽略),grok → --reasoning-effort(无 max,按 xhigh),deepagents → reasoning_effort(仅云端/OpenRouter 渠道,本地模型不传);kimi CLI 无对应参数,不受影响。越深越稳但越慢、token 消耗越高;「引擎默认」不传任何参数,沿用各引擎自身配置(如 ~/.claude/settings.json 的 effortLevel、~/.codex/config.toml 的 model_reasoning_effort)。全局设置,对所有 Agent 生效,保存后对后续启动的工单生效。
对话记忆额度(KB,默认 16):创作型 Agent 每次运行接续上次会话,多轮对话有连续记忆;单个会话历史超过该额度自动新开会话防膨胀(扇出型无状态 Agent 本就每单全新会话,不受此项影响)。调大可保留更长的连续记忆,但 resume 每轮重发全部历史,越大越慢、token 消耗越高。拖到 0 即完全关闭:所有 Agent(含总制片)每次运行/发言都是全新会话,跨工单信息只靠落盘产物(bible、工单档案等)传递,可显著省 token,但对话上下文不再延续。全局设置,保存后立即对后续运行生效;调小或关闭期间会话号照常回存,重新调大后从最近一次会话继续。
