项目

📋 复制项目

完整复制当前项目目录(全部产物、运行记录)为一个全新项目;复制完成后返回当前项目的控制台,新项目可在顶栏项目选择中打开。大项目可能占用较多磁盘空间。

💾 自动备份

开启后,每次签字都会把当前项目目录整份打成 zip 压缩包,放到下面的备份目录;文件名由项目名和时间戳组成,如 demo-20261022-153000.zip。设置对所有项目生效。

备份可用控制台顶栏项目下拉里的「› 导入项目…」还原。每份备份与项目目录差不多大,旧备份不会自动删除,请留意磁盘空间。

⚠️ 危险操作:删除当前项目

将永久删除项目 的整个目录(全部产物、运行记录),不可恢复。请输入项目名称以解锁删除按钮。

⚠️ 确认删除项目

即将永久删除项目 的全部文件。

此操作不可恢复:产物、运行记录将一并删除。删除后自动跳转到第一个项目。
