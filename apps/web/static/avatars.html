🧑‍🎨 虚拟人像资产库

火山方舟私域素材库:入库的人物形象图在生成视频时以资产 URI 提交,规避人脸参考图审核拦截

📋 使用前准备

  1. 在火山方舟开通 高级创作权益包(私域虚拟人像素材库的前置条件)。
  2. 在火山引擎控制台 API 访问密钥管理 创建并获取 Access Key / Secret Key(IAM 密钥,非 ark- 开头的方舟 API Key),填入下方并保存。
  3. 点击「启用」后,可在下方管理已入库的素材;人物预览页每张形象图会出现「入库」按钮,分镜重出时已入库(Active)的参考图自动以资产 URI(asset://素材ID)提交。
注意:上传入库为异步审核(Processing → Active/Failed),仅 Active 状态的素材可用于视频生成;素材按方舟「项目」隔离,下方 ProjectName 须与「生成模型」页视频生成所用方舟 API Key 所属项目一致(默认 default)。

🔑 密钥与开关

Access Key / Secret Key 留空时,自动使用「⚙️ 设置 → 文件托管 → 火山引擎 TOS」已配置的 AK/SK(或环境变量 TOS_ACCESS_KEY/TOS_SECRET_KEY)。
