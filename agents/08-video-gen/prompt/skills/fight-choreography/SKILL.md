# 武打设计(Fight Choreography)

> 模型看不见「激烈」「高能」,只看得见谁的哪件兵器沿哪条线打向哪里、对方怎么应、身体被带到哪、地板和栏杆留下了什么。本技能只做一件事:把上游的打斗动作事实翻译成这条看得见的因果链。

## 适用范围(先判定,不适用就不要读下去)

- **适用**:组内至少一镜的 `shot_list.json#poses[<id>].action` 或 `blocking.json` 动作节拍 beats 写明了交手动作——出剑/出枪/劈砍/格挡/闪避/拳脚/擒拿/摔投/追击/兵器对撞等,且交手双方(或一方与其目标)同镜可见。
- **不适用**:只是持械站立、对峙、练功摆姿、收剑入鞘、战后余波;对白组里顺手拍桌/推搡一下;无人物的环境破坏镜。这些按 SOUL.md「动作写法四条」常规写。
- **与 high-density-fight 的关系**:整组大半时长都在连续交手、且项目勾了 `high-density-fight` 时,组级结构(资产账本、阶段接力、收束)以它为准,本技能只管逐招措辞;其余含交手镜的组只用本技能。
- **分工边界**:打什么、谁胜谁负、用什么兵器、几镜几秒、机位运镜——分别归剧本/storyboard·shot-planning(`poses.action`)/blocking(走位与节拍)/camera-movement(camera.json)。本技能只管**怎么把已定的动作写成模型打得出来的画面文字**。上游只写了「二人交手数合」这类笼统动作时,允许在下述「事实账本」范围内补出具体招式(属最小补全),但不得改胜负、改兵器、改出场人、改终点站位、加镜减镜;上游连谁攻谁守都没给的,回执写明缺项,由 orchestrator 回派 blocking 补节拍,不自行编剧情。

## 工作流

1. **建事实账本(每个交手者一行)**:兵器种类/数量/长度/持握手(取 `bible/props.json` 的 `prompt_token` 与道具卡,**逐字沿用、不改尺寸**)、服装里会甩动的部件(袍摆/斗笠/红缨/发丝)、体型与战斗气质(personality)、本组起点/终点站位(blocking)、本组胜负或收束状态(shot_list/blocking)、场景里可被打坏或可借力的真实物件(场景卡/layout 地标:木柱/栏杆/桌/瓦面/竹竿——**只用场景卡里有的**)。图里没有、上游没给的兵器与超自然能力一律不新增;无兵器者全程徒手。
2. **按载体选招式语汇**(见 §载体表)。双方载体不同就写出差异:长兵打距离、短兵抢贴身、徒手不裸手接刃。
3. **逐镜写攻防链**(见 §攻防链):每个 Shot 段的「主体动作与表情」位写 1–3 个完整交换,镜时长 ≤2s 写 1 个,2–4s 写 2 个,>4s 最多 3 个;宁少勿糊——模型一镜里塞不下五招。**受节拍预算约束(2026-10-03,SOUL「节拍预算」)**:攻防链各环节只能展开 blocking 该镜已有的节拍,≤1s 的镜只有一拍就只写攻击线 + 接触/险过这一拍,受力位移与环境结果没在 blocking 里就不写;顺序连接词数 ≤ 节拍数 + 1(机检 prompt_beats_bound)。
4. **镜间接力**:下一镜开头继承上一镜结尾的位置、朝向、速度方向、高度/支撑面、兵器状态、谁占优、环境余波中的至少四项;禁止「打完一招—双方复位—再起一招」。
5. **写重量与表情**(见 §真实感清单),写声音(只写画面里动作产生的声音,cue 文本仍逐字取自 audio_cues)。
6. **组尾状态**:按上游给定的胜负/收束写;上游未给胜负的组,结尾停在仍在进行的攻击、闪避、追击或「兵刃互指一寸」的临界点,不擅自缴械、跪地、分胜负。
7. 自检(见 §自检清单),回执登记。

## 载体表(选语汇,不混用)

| 载体 | 动作语汇 | 必写的物理反馈 |
|---|---|---|
| 剑(中国剑法) | 刺、撩、削、点、格、挂、压、反刺、封喉;腕部翻转、剑尖连点,短促精准 | 剑身偏转与震颤、贴着衣襟/袖口/斗笠边缘擦过、被逼离中线 |
| 刀 | 劈、砍、扫、撩、架;腰胯带动,势大力沉 | 刀势惯性把身体带出半步、格挡方膝盖被压弯 |
| 枪/长柄 | 拦、拿、扎、挑、劈棍、横扫、枪尾短打、回马枪、换把 | 距离优势、杆身转向惯性、回收时间、被贴身后的不利;红缨/杆梢延迟甩动 |
| 钝器 | 砸、压、推、撞、抡 | 凹陷/碎裂、低频重击、大幅击退;不写成轻飘剑法 |
| 徒手 | 拳、掌、肘、膝、腿、肩撞、擒拿、卸力、摔投、扫腿 | 双手始终空置;对持械者靠侧闪、贴身、踢腕、控臂、抓非锋利部位,**不裸手硬接锋刃** |
| 轻功/腾跃 | 蹬地、踏柱、踩栏、借竹竿回弹、短距离弹跳 | 必有起跳发力点与明确落点;上升时衣袍下坠/后甩,落地膝盖弯曲缓冲、脚底滑出半步、地面震起尘;禁悬空不受力 |
| 生物/机械 | 沿自身结构:扑、咬、甩尾、振翼俯冲 / 关节、推进器、装甲 | 足数、关节方向、转弯半径可信;不套人类剑术 |

## 攻防链(每个关键交换写满)

`起势与重心 → 明确攻击线(从哪到哪,打哪个部位) → 接触或险过(差多少:一寸、擦过斗笠边缘) → 对方的应对(针对这条线) → 受力与位移(谁被震退、退几步、往哪偏) → 环境结果(可选,材质与方向要对) → 由此露出的破绽触发下一动作`

- 同一条连续攻击线上的连击可共用一组受力/环境反馈(「连续三剑:第一剑逼肩,第二剑点腕,第三剑直取腹部,对方用枪杆中段连挡,每挡一次手臂一震、后撤半步」),不必每击都打坏东西。
- 格挡和落空**保留动量并改线**:被格开的剑顺势旋身变撩,落空的枪借惯性回身成回马枪。
- 防守针对真实攻击线,反击利用对方上一动作留下的重心、距离或视线漏洞;双方不是轮流表演。
- 环境破坏合材质合方向:横击侧向断裂、重砸向下塌陷、刺入沿贯穿线开裂;碎屑延迟落下;至少让一次破坏影响后面的路线或站位(踩碎的瓦让人脚下一滑)。全组破坏点 ≤3 处,别拆房。

## 真实感清单

- **重量**:转身由脚步和腰胯带动;重击让承受方身体下沉、膝盖弯曲、脚底在地面滑出一段;衣袍、缨穗、发丝比身体慢半拍。
- **速度但看得清**:快靠「突然、短促、连贯」写出来,不靠堆「极快」「闪电般」;每招写清起止。慢动作全组至多一处、≤1s,只放在组尾临界点,且上游节奏允许时才用。
- **表情挂在动作上**:咬牙、下颌绷紧、瞳孔一缩、闷哼后退、眼角抽动、喘息——写在受力或险过的那一刻,不写「杀气腾腾」这类抽象词(与「动作写法四条」④同口径)。
- **险**:致命招写「差一寸」:枪尖擦过斗笠边缘、剑锋贴着袖口划过、剑尖停在喉前一寸。除非上游明定受伤/死亡,不写见血、断肢、穿刺入体(亦防渠道审核拒片)。
- **声音**:脚步重踏、衣袍破风、兵器撞击与余震、木板震动、碎物落地、急促呼吸;无配乐、无旁白(已有对白照 SOUL 处理)。

## 与团队规范的优先级

- SOUL.md 的结构锚点、主体定义前置、上游逐字片段(风格串/光照/站位 `space_fragment_en`/服装/道具 `prompt_token`/cue/route_en)、冻结 `{}` 台词、Identity lock、宿主写入的固定段——**一律不动**;武打散文只填各 Shot 段「主体动作与表情」位。
- **一镜一运镜不变**:运镜句仍只写 camera.json 指定的单一运镜。案例里的「快切」「甩镜」「手持跟拍+横移」不得搬进运镜句;要速度感,写进动作本身(兵器从前景掠过、红缨扫过画面形成遮挡、落地时尘土震起),或由 shot-planning 拆更多短镜。镜数不够打不开的,回执建议回派 shot-planning,不自行加 Shot 段。
- **本技能在适用组内放宽「动作写法四条」②**(优先低缓动作、规避高爆发):打斗组允许高爆发动作,但遵守其括注——该镜其余动态元素从简(背景人物不动、环境动态只留被打到的那一处),一镜内只聚焦一对交手者。①量化肢体、③惯性承接、④情绪外化照旧且从严。
- 与引擎 skill(sd20/sd25/h3/wan3-pe)并用:引擎 skill 管模板与符号,本技能管打斗内容。时间写法随引擎:Seedance 不写秒数,用动作先后承接;H3 可写时间码。
- 与 performance-direction 并用时:边打边说的镜,台词触发词与 `end_state` 纪律照旧,打斗链写在台词前后,不把台词拆到攻防链中间之外的位置。
- 风格词(「徐克武侠电影质感」「胶片颗粒」之类)归 style.json 的风格串,**不在此另加**;负面词只并入 `Global constraints:`,从 §负面清单挑与本组相关的 3–6 条,不整段照搬。

## 负面清单(按需挑用,写进 Global constraints)

不要漂浮飞行/悬空不受力、不要吊威亚假感、不要游戏动作与技能特效、不要发光兵器与魔法光效、不要兵器变形/变短/换手/凭空消失、不要动作软绵像跳舞、不要原地轮流互砍、不要表情僵硬、不要慢动作过多、不要乱切看不清招式、不要手指畸形。

## 正反例

- ✗ 「两人激烈交战,刀光剑影,打得难解难分。」
- ✓ 「白袍枪客猛然蹬地前冲,双手沿枪杆滑把,先横拦压住对方剑锋,顺势直扎咽喉;斗笠剑客后撤两步、身体后仰,枪尖擦过斗笠边缘,红缨慢半拍甩过他眼前;他借后仰之势压低身体贴着枪杆切入,长剑自下斜撩,逼得枪客用枪杆中段硬挡,手臂一震,后退半步。」
- ✗ 「他腾空飞起,凌空一剑。」
- ✓ 「他后脚重踩木柱下沿借力跃起,衣袍因上升被向下拽,双手持剑下劈;枪客抬枪横架,双臂承力,膝盖一弯,脚底在木板上滑出半步;他落地屈膝缓冲,地板震起一层灰。」

更多完整范例(五组 15s 武侠对决,含枪对剑、双剑楼阁、雨中屋顶)见 `references/wuxia-cases.md`——**只学其攻防链、重量感与表情写法**;其「镜头 N|时间码」排版、风格开头、复合运镜与整段负面词属单条独立提示词的写法,不照搬进本团队的组结构。

## 自检清单(写入 skill 回执)

1. 每个交手者只用了账本里的兵器/能力,`prompt_token` 逐字未改,无兵器者徒手;
2. 每个打斗镜的关键交换含:攻击线 + 接触或险过 + 受力位移 + 下一动作触发;
3. 相邻镜无复位,位置/朝向/优势/兵器状态接得上;
4. 腾跃有起跳点与落点缓冲,无悬空不受力;
5. 运镜句仍是 camera.json 的单一运镜,Shot 段数未变;
6. 组尾状态与上游胜负一致(未定胜负则停在进行中或临界点);
7. 无见血/断肢等上游未定的伤害,破坏点 ≤3 且用的是场景卡里的物件。
