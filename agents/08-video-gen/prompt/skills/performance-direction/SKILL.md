# 表演控制(Performance Direction)

> 模型看不见「悲伤」「羞愧」,只看得见悲伤和羞愧在脸上、身体上、声音里留下的证据。本技能的工作只有一件:把导演层的表演意图翻译成证据。

## 适用范围(先判定,不适用就不要读下去)

- **适用**:组 `audio_plan == dialogue`;或组所属场次在 `directing/epNN/directing_plan.md` / `story/episodes/epNN/pacing.json#scenes[].emotion.in_scene_peak` 被标为情绪峰值/重点场次。
- **不适用**:ambient_only / narration_over 组、纯动作或纯氛围组、无人物面部可见的组(远景/背影)。这些组按 SOUL.md「动作写法四条」常规写即可。
- 输入依赖:每镜 `blocking.json#characters[].performance`(blocking agent 产出的表演节拍,字段见下)。**缺该字段不得自行编导演意图**——回派 blocking 补写;存量项目未补写前按常规写法降级并在回执说明。

## 工作流

1. 读本组每镜 blocking.json 的 `performance` 节拍:`goal`(此刻想争取什么)、`arc_from → arc_to`(情绪从哪走向哪)、`trigger`(哪句台词、哪个词触发变化)、`forbidden_early`(哪些反应不能在触发前出现)、`end_state`(说完后的静止状态短语)。
2. 读 `dialogue-rewrite` 对白层该句的情绪标签与估时,读 `personality.json` 的表演基调(该角色情绪外露度、习惯性防御动作)。
3. **先看见再命名**:按「脸的五个观察区域」逐区问四件事——哪里在动、往哪个方向动、动作多强、被哪个词触发(见 §五区观察法)。先用人话写下看得见的动作。
4. **再用 AU 校准**:对照 `references/au-sheet.md`,核对写下的动作对应哪几个 AU、强度落在 A–E 哪一档、三阶段(起始/峰值/消退)是否各有着落;发现「一上来就到峰值」「愤怒和哭同时端上来」这类失真就改回自然语言。**AU 编号与强度只记入 `grpNNN.json#performance[].au_calibration`,严禁写进 video_prompt 正文**(SOUL.md 禁写元信息:编码会被渲染成画面文字;官方亦说编码不保证被解析)。
5. 按 §八维公式把该角色在该 Shot 段的表演写成一段连贯散文,嵌入 SOUL.md 规定的 Shot 段结构(运镜 → 主体动作与表情 → 空间位置 → 音频)——表演散文落在「主体动作与表情」位,不改结构锚点、不动逐字片段、不动 `{}` 台词。
6. 按 `references/engine-adapters.md` 处理「时间段」维:Seedance 2.0/2.5 不写秒数,用台词做时间轴;H3 可写时间码。
7. 自检:每个说话角色的 Shot 段必含①触发词绑定短语(触发词在 `{}` 台词之外再出现一次,如「说到『被杀』时」)、②`end_state` 逐字命中、③触发词之前无 `forbidden_early` 列出的反应;正文无 `AU\d` 字样。跑 `python3 code/performance_bound_check.py --project <slug> --ep <epNN>`。

## 八维公式(每个说话角色 × 每个 Shot 段)

| 维 | 写什么 | 提醒 |
|---|---|---|
| ① 时间段 | 这段表演落在台词的哪一段:说话前 / 前半句 / 说到『X』时 / 说完后 | Seedance 用台词做时间轴,不写秒;H3 可写 `At 00:0x.000` |
| ② 人物目的 | 此刻想争取什么(不是「感到什么」) | 取 blocking `goal`,写成可见的争取动作(逼视、不让对方走、把话说完) |
| ③ 情绪变化 | 从哪种状态走向哪种(`arc_from → arc_to`),中间的保护层怎么失效 | 情绪曲线:先用愤怒保护自己,撑不住了悲伤才出来;禁止两种情绪同时端上来 |
| ④ 台词触发词 | 哪个词让动作发生、哪个词要加重 | 触发词在台词 `{}` 外再写一次:「说到『被杀』时」 |
| ⑤ 面部动作(五区) | 眉 / 眼 / 鼻翼 / 唇 / 下巴,各写「往哪动 + 多强」 | 自然语言;AU 只在 json 里校准 |
| ⑥ 目光·身体·声音 | 视线落点与移开时机、躯干朝向与前后倾、手在哪;音量高低、快慢、哪句破音或压低 | 声音变化写在台词旁,不写「颤抖的声音说」这种笼统句 |
| ⑦ 呼吸与停顿 | 哪里吸气、哪里屏住、停顿多长(短促 / 不到半秒 / 一拍)、停顿时脸在做什么 | 停顿不是空白:停顿时人物心里的声音超过嘴里的声音,脸要有事 |
| ⑧ 结束状态 | 说完最后一个词后进入什么静止状态、保持到镜尾 | 逐字拼入 blocking `end_state`(机检 performance_bound) |

**禁止提前反应**(`forbidden_early`):在触发词出现之前,这些反应一律不得出现在描写中(例:D01 问句阶段眼眶不得湿润、肩膀不得颤)。这是让「保护层慢慢失效」成立的唯一手段——模型拿到「悲伤」两个字会从第一帧就哭。

## 五区观察法(先看见,再命名)

把脸分成五个区,每区问四件事:**哪里在动 → 往哪个方向动 → 动作有多强 → 被哪句台词触发**。

| 区 | 常见可见动作(自然语言) | 对应 AU(校准用) |
|---|---|---|
| 眉 | 眉毛内侧缓缓抬起 / 眉头向内向下压 / 眉毛外侧挑起 | AU1 / AU4 / AU2 |
| 眼 | 上眼睑抬高露出更多眼白 / 眼帘收紧 / 眼眶湿润但泪不落 / 目光下落离开对方不到半秒 / 眨眼变少 | AU5 / AU7 / AU6(脸颊上抬)/ AU43·45 |
| 鼻翼 | 鼻翼张开 / 鼻梁皱起 | AU38 / AU9 |
| 唇 | 嘴角轻微下沉 / 嘴唇压紧抿成一线 / 嘴唇分开却没出声 / 嘴角单侧扯动 / 下唇轻抖 | AU15 / AU23·24 / AU25 / AU12·14 / AU16 |
| 下巴 | 下巴绷紧上抬 / 下颌张开 / 咬肌鼓起 | AU17 / AU26·27 / AU23 |

三阶段:每个动作写清**起始**(刚刚能察觉)→**峰值**(在触发词上)→**消退**(说完后减弱或保持)。愤怒不是从第一帧把所有肌肉拉到最大:先眉头下压、眼帘收紧、嘴唇压紧,说到刺激词时嘴唇分开、下颌张紧、鼻翼张开形成短促爆发,说完立即减弱——才有「忍住—失控—重新控制」的过程。

## 正反例

**悲伤(隐忍)**
- ✗ 「她非常悲伤,眼泪止不住地流下来。」
- ✓ 「说话前她的眉毛内侧缓缓抬起,嘴角轻微下沉,下巴开始绷紧;说到『被杀』时她张开嘴想继续,却没有立刻发出声音,目光向下离开对方不到半秒;眼眶逐渐湿润但眼泪不落;说完后嘴唇合拢,视线重新回到对方脸上,不再眨眼。」(json 校准:AU1 B、AU15 B、AU17 B;峰值在『被杀』;AU25 短促起落)

**愤怒(压抑→爆发→收回)**
- ✗ 「他愤怒地大声咆哮。」
- ✓ 「开口前他先把嘴唇压紧、咬住下颌,眉头向内向下压;前半句声音低沉平稳;说到『滚』字时鼻翼张开、身体向前探出,嘴唇分开、下颌张紧,音量短促抬高;最后一个字落下后立刻闭上嘴,身体退回原位,眼帘仍收紧盯着对方。」(json 校准:AU4 C、AU7 C、AU23 B → 『滚』上 AU25/AU26 D、AU38 → 消退回 AU23)

**台词与表情融合**
- ✗ 「女人非常悲伤地说:{那我的人生呢?那我呢?}」
- ✓ 「{那我的人生呢?} 第一句音量偏高,眼帘收紧仍在质问;两句之间一次短促吸气,目光向下离开不到半秒——她在决定要不要把最脆弱的那句说出口;{那我呢?} 第二句明显更轻更慢,她重新看回对方,但眼神里的攻击性已经消失。」

## 与团队规范的优先级

- SOUL.md 的结构锚点(`Overall visual style:` / `Shot N:` / `Global constraints:` / `[Image N]` / `[Audio N]`)、主体定义前置、上游逐字片段(风格串 / 光照 / 站位 / 服装 / 道具 / cue / route_en)、冻结版 `{}` 台词、Identity lock 与防重复句——**一律不动**;表演散文只填在各 Shot 段「主体动作与表情」位。
- 与 sd20 / sd25-pe / h3 引擎 skill 并用:引擎 skill 管模板与符号,本技能管表演内容;情绪外化对照表(sd20 guide-zh.md §2.3)是本技能 ⑤⑥ 维的粗粒度版本,两者冲突时以本技能的五区写法为准(更细、带触发词与时序)。
- 「动作写法四条」②(优先低缓细微动作)仍然有效:表演的量宁小勿大——颤的是声音不是脸;失控只给一个词的长度。
- 停顿吃组时长:节拍要求的停顿总和超过组时长 ×0.3(对白适配余量)时,不得自行删节拍,上报 orchestrator 回派 shot-planning 调组。
