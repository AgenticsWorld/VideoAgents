# FACS 动作单元(AU)校准表

> 用途:写完自然语言的面部动作后,用本表核对「动了哪块肌肉、动到几档、三阶段是否齐全」。AU 编号与强度**只记入 `grpNNN.json#performance[].au_calibration`**,不进 video_prompt 正文。图版见同目录 `AUsheet.jpeg`。

## 强度档(FACS 标准)

| 档 | 含义 | 写进自然语言时的措辞 |
|---|---|---|
| A | 刚刚能察觉(trace) | 「几乎看不出」「微微」 |
| B | 轻度(slight) | 「轻微」「略」 |
| C | 明显(marked/pronounced) | 「明显」「清楚地」 |
| D | 强烈(severe/extreme) | 「用力」「大幅」 |
| E | 极限(maximum) | 「到极限」——影视表演极少用,只给一个词的长度 |

## 三阶段

每个 AU 都有 **onset(起始)→ apex(峰值)→ offset(消退)**。写表演时三段各要有着落:起始落在说话前或前半句,峰值落在触发词上,消退落在说完后(减弱或保持成结束状态)。只写峰值 = 从第一帧就到最大。

## 常见组合(校准用,不是公式)

同一个 AU 配不同伙伴会变成不同情绪——这是为什么不能只扔编码:

| 组合 | 倾向 | 配合的身体/声音线索 |
|---|---|---|
| AU4 + AU7 + AU23(+AU38 爆发时 AU25/26) | 压抑的愤怒 → 爆发 | 咬牙、身体前倾、盯视;音量在触发词上短促抬高 |
| AU1 + AU15 + AU17 | 隐忍的悲伤 | 目光下落、下唇微抖;音量走低、句尾变慢 |
| AU1 + AU4 + AU15 | 痛苦、哀求 | 眉心上提又下压;声音发紧 |
| AU1 + AU2 + AU5 + AU26 | 惊讶 / 恐惧初起 | 身体后撤半步;倒吸一口气 |
| AU4 + AU5 + AU7 + AU23 | 瞪视的怒 | 不眨眼;声音压低 |
| AU6 + AU12 | 真笑 | 眼角纹;肩膀放松 |
| AU12 单侧 / AU14 | 轻蔑、假笑 | 头微偏;语速不变 |
| AU9 + AU10 (+AU16) | 厌恶 | 头后仰、鼻子皱起 |
| AU20 + AU5 + AU25 | 恐惧 | 呼吸变浅变快;声音发抖 |
| AU17 + AU24 + AU43 | 承受、忍住不说 | 闭眼一拍再睁开;停顿 |
| AU28 + AU41 | 尴尬、羞愧 | 目光向下向侧离开;声音变小 |

## 校准问答(写完后逐项过)

1. 每个动作有没有「起始 → 峰值 → 消退」?峰值是否落在触发词上?
2. 有没有两种相反情绪同时到峰值(愤怒 D + 流泪)?若有,拆成先后:保护层先撑、撑不住再出下一种。
3. 强度是否超过 C?超过的只允许出现在一个词的长度里,且必须有消退。
4. 触发词之前有没有出现 `forbidden_early` 里的反应?
5. 结束状态是不是一个可维持到镜尾的静止状态(闭唇、目光落点、不眨眼、肩膀不动)?
