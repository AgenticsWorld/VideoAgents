# 按引擎适配「时间段」维与符号

八维公式的其余七维引擎无关;唯独 ① 时间段的写法必须按生效视频模型换。判定生效模型看系统提示词注入的引擎段(sd20-pe / sd25-pe / h3-pe / wan3-pe 四选一)。

## Seedance 2.0 系列(`skills/sd20-pe`)

- 官方明示:**模型对精确时间(如 0–3 秒)的支持不稳定,强行限制时长可能导致生成结果异常**(guide-zh.md §2.2)。
- 因此**不写秒数**。用台词本身做时间轴,时间段写成相对表述:
  - `说话前` / `开口前`
  - `前半句` / `后半句` / `第一句` / `第二句`
  - `说到句尾四个字时` / `说到最后一个字时`(触发点只用位置说法,不引台词原词)
  - `两句之间`
  - `最后一个字落下后` / `说完后`
- 停顿长度用相对词:`短促` / `不到半秒` / `停一拍` / `明显停顿`。
- 表演散文落在 `Shot N:` 段「主体动作与表情」位,顺序:说话前状态 → `{台词}` → 触发点处的变化 → 呼吸/停顿 → 说完后的结束状态。**一句台词只写一个 `{}`,不拆段;`{}` 之外不引台词原词**(SKILL.md §台词写法两条硬纪律,2026-10-05),`{}` 内文本与冻结版逐字一致。
- 音效 `<>`、台词 `{}` 符号照旧;不用 `（）`(官方音乐符号,本仓库禁音乐)。

## Seedance 2.5(`skills/sd25-pe`)

- 同 2.0:**不得为对齐时长新建 `0-8 秒` 这类数字时间段**(sd25-pe §长视频与时间段);用「阶段」组织。
- sd25-pe 已有两条与本技能同向的规则,直接叠加使用:
  - 「把内心活动转成可见动作、表情、台词或旁白」——本技能的五区写法就是它的细化;
  - 「因果揭示镜头先呈现触发原因,再呈现人物反应」——与本技能「禁止提前反应」同一条纪律,触发原因 = 触发词或画面事件。
- 可用 sd25-pe 的「情绪表演/运镜/声音表达技法」段作散文润色,但表演内容仍以 blocking `performance` 节拍为准。

## MiniMax H3(`skills/h3-pe`)

- H3 的 `detailed_description` 按时间码组织(`[Shot 2] At 00:09.000, ...`),**允许写秒**。时间段维可直接落在时间码上:`At 00:03.500 she says {...}; at 00:05.200, on the last two words, her ...`。
- 表演散文写在对应 `[Shot N]` 段内,与 H3 的 composition / subjects / actions / camera / sound 顺序并存;触发点用时间码或位置说法(`on the last word` / `in the second half of the line`),不写 `on the word "…"` 把台词原词引出来;`{}` 台词保持原语言。
- 时间码总和须与 `--duration` 一致(H3 skill 既有规则);停顿要占时间码里的实际长度。

## 阿里 Wan 3.0(`skills/wan3-pe`)

- wan3-pe 的【情节概要】按编号节点组织;**用户/上游写了时间戳时按原文逐字带入**(`镜头N xx-xx秒` 开头),没写时各节点保持纯编号、不自行补秒数(wan3-pe 原则 7「参数分离」+ 最终自检「镜头时间戳按用户原文逐字带入」)。因此时间段维的写法跟随 shot_list:有逐镜时长就写在节点头,表演触发点仍用相对的位置说法(`说到后半句时` / `说到句尾两个字时`)绑定台词,不引台词原词,不在节点内部再切细秒数。
- 表演散文落在对应情节节点内,顺序同 2.0:说话前状态 → 台词 → 触发点处的变化 → 停顿 → 说完后的结束状态;台词按 wan3-pe「使用音频N的音色说：'逐字原文'」写法与说话人绑定,`{}` 内文本仍须与冻结版逐字一致。
- wan3-pe「只整理不丰富」的原则与本技能不冲突:表演节拍来自 blocking `performance`,属于上游既定内容,不算加戏;【负面提示词】只放上游明确排除项,不把 AU 或表演禁忌写进去。

## 通用

- 位置说法的语言随界面语言(中文界面写「说到后半句时」「说到句尾四个字时」,英文界面写 `in the second half of the line` / `on the last word`);所用短语逐字记入 `grpNNN.json#performance[].trigger_anchor`,机检核它出现在该 Shot 段 `{}` 之外,并查 `{}` 之外有没有用引号引出台词里的词、一句台词有没有拆成多个 `{}`。
- `end_state` 逐字拼入(同 `space_fragment_en` 纪律),不翻译、不改写。
- AU 编号(`AU1`…`AU46`)任何引擎都不进正文。
