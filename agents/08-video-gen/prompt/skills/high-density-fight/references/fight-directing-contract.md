# 打斗导演合同(组级)

用于两方主体、参考素材驱动、一个生成组(通常 5–15 秒)的电影级连续打斗。它把动作导演、武术指导、角色行为和提示词写作分开处理,避免「角色换一套皮也成立」的泛用招式堆叠。改编自 high-density-fight-prompt 的《15 秒高密度打斗导演合同》,输入输出按本项目的组/镜结构重订。

## 0. 时长路由

以组 `total_duration_s` 选结构(组总时长是生成硬约束,镜级 `duration_s` 只是节奏意图——阶段按镜级累计时间**按比例**落位,不写死秒数):

- **≥ 11 秒**:五段状态接力。比例约 20% / 20% / 27% / 20% / 13%(15 秒组即 0–3 / 3–6 / 6–10 / 10–13 / 13–15)。
- **≤ 10 秒**:四段短结构——即时抢攻 → 接触后变线 → 持续追击与攻守转换 → 进行中的切出或上游指定结果。不得把五段终局压缩塞进短组。
- 短组且上游未定胜负:最后一帧仍在攻击、闪避、追击、滑行、卸力或环境连锁中;定了胜负:最终命中后保留前冲、滑行、追击或卸力,不以摆姿收尾。
- 一场战斗跨多个组时,每组各自路由,但只有**最后一组**写终结段;前面的组末段改写为「优势易手并把状态交给下一组」,其 `handoff` 必须与下一组 `continuity_from`/尾帧承接一致。
- 「无蓄力/无停顿/不停/全程连打」:任何结构都叠加无停顿限制——角色、兵器、环境物或摄影机至少一项持续运动,禁止收势、制动和静态展示。

## 1. 输入与事实优先级

本项目的输入:`shot_list.json`(本组各镜 `poses[].action`、`duration_s`、`characters`、`scene_id`)、`blocking.json`(站位、走位、beats)、`camera.json`(每镜单一运镜)、组 `refs`/`video_refs`(角色图、场景/背景图、白模视频)、`bible/props.json`(兵器卡与 `prompt_token`)、`personality.json`(战斗气质)、剧本该场的胜负与伤情。

冲突时按以下顺序决定:

1. 用户/剧本/上游产物明确指定的角色、装备、能力、动作、胜负、时间点与禁止项;
2. 参考图清楚可见的外观、服装、持有物、身体结构、能力介质和能量效果;
3. 已确认且与当前版本相符的战斗习惯(personality、前集已成片的打法);
4. 保持动作连续性所需的最小补全;
5. 导演原创。

不从职业称号、门派名自动补兵器、招式或能力。

## 2. 参考素材与资产账本

逐份为素材分配唯一职责(与 SOUL.md 的 `[Image N]`/`[Video N]` 绑定一致,不另起编号):

- **角色图/生物图**:锁脸、发型、体型、服装、配色、身体结构和清楚可见的装备;不继承其站姿与海报构图。三视图/sheet 里同一角色重复出现不增加人数。
- **场景图/背景图(shot plates)**:锁建筑、材质、光源、天气、地形、通道和高低差——环境破坏与借力点只能从这里取。
- **白模参考视频**:锁站位、动线、相对朝向与机位;不提供招式细节。
- **尾帧/承接图**:锁本组开场的身份、朝向、接触关系、支撑面;允许动作立即推动重新取景,不要求复刻其构图。

为 A/B 分别记录:外形锚点、身体结构、服装可动部件、战斗目标、兵器种类/数量/材质/尺寸/持握、能力来源、能量规则、移动条件、开场位置、终点位置和禁止补全项。兵器不得无因变形、消失、复制、换手或改变尺寸;无兵器角色始终徒手。

超自然能力只在上游明确指定或图片清楚显示时使用。无能力角色以体态、衣料惯性、空气压缩、尘土、碎石、摩擦和材质破坏表现速度与力量。能力必须写清来源、方向、接触对象和消散/残留结果;不能脱离身体动作凭空爆炸,也不能用大面积特效遮挡攻防。

## 3. 战斗载体自动路由与攻防适配

按每个主体真实可见或上游明确指定的资产选主载体;可组合已具备的两种(「长剑+身体冲撞」),不为热闹补第三套体系。

| 可见条件 | 动作路由 | 关键物理反馈 |
| --- | --- | --- |
| 刃器 | 斩、刺、挑、格、拨、压、绕、滑刃、贯穿;攻击线围绕刃口与剑尖展开。中国剑:刺、撩、削、点、格、挂、压、反刺。 | 切割轨迹、刀剑偏转与震颤、裂口与断面、目标被逼离中线。 |
| 长柄武器 | 中线压迫、远距离刺击、压杆、挑击、横扫、枪尾或柄部短打、折线追刺、回马攻击;枪:拦、拿、扎、劈棍、换把。 | 距离优势、杆身转向惯性、回收时间和被贴身后的不利;缨穗延迟甩动。 |
| 钝器 | 砸、压、推、撞、抡、震击。 | 凹陷、塌陷、碎裂、低频冲击与大幅击退;不写成轻飘的剑法。 |
| 远程武器 | 瞄准、发射、追踪、规避、拦截、换位。 | 弹道、射线方向、遮挡关系、发射间隔与掩体结果清楚。 |
| 徒手 | 拳、掌、肘、膝、腿、肩撞、擒拿、卸力、翻摔、贴身闪避、踏墙借力与身体冲撞。 | 双手保持空置;持械对手的锋刃靠切线、控住非锋利部位、贴身或环境借力处理。 |
| 能力型角色 | 牵引、压缩、塑形、包裹、偏转、束缚、局部强化、环境操控。 | 能力从既有身体部位、手势、兵器或机械结构产生,写明来源、方向、接触对象与残留。 |
| 飞行生物 | 振翼、收翼、俯冲、翻滚、爪击、空中制动。 | 翅膀结构、升力、气流与转弯半径可信。 |
| 四足或多足生物 | 蹬地、扑击、攀附、撕咬、甩尾、重心转移。 | 足数、关节方向、抓地力与惯性正确。 |
| 机械或载具 | 围绕可见推进器、轮组、机械臂、炮口、关节与装甲启动、加速、规避、撞击或制动。 | 不增加图中不存在的功能;反馈来自真实的传动、装甲、轮胎或推进结构。 |

按双方载体差异再校验:

- **双方持械**:按长度、重量、攻击方向与结构差异设计压制、滑开、缠绕、拆线和反震,不把所有兵器写成相同剑法。
- **持械对徒手**:徒手方侧闪、贴身切入、踢腕、控臂、抓握非锋利部位、肩撞、翻摔或借环境反制;除非上游明确设定,不裸手硬接锋刃。
- **持械对能力**:能力方通过有明确来源的局部防御、牵引、偏转、束缚或身体强化处理攻击;写清与兵器的接触点和受力结果。
- **双方徒手**:只用拳脚、擒拿、摔投、冲撞和地形借力;不写刀光、剑鸣、金属碰撞。
- **双方能力**:围绕接触、切断、包围、偏转、压缩和环境传播做近中距离攻防;不退化为无来源的远程光团对轰。
- **生物、机械、巨物或载具**:以真实身体或机械结构交锋,不强迫其套用人类剑术、拳术或轻功。人对巨物:人打关节、眼、腹等可及部位并借其身体攀附,巨物以体量封路、扫荡、压砸,体量差必须体现在位移幅度上。

## 4. 三层编排 + 一层写作

**动作导演**:先定双方冲突目的、空间主轴、路线节点、危险区、强度升级、第一次逆转、收束落点,以及每个阶段要让观众看清的一件事。空间主轴与路线必须落在 blocking 的起点/终点与白模动线之内。

**武术指导**:按真实载体设计(§3)。每个**关键攻防交换或优势转换**必须完整;同一条连续攻击线内的多次连击可共同满足下列反馈,不必为每一击强加环境破坏:

`起势/重心 → 加速 → 明确攻击线 → 接触或险些命中 → 合理应对 → 形变/反震 → 沿力线位移 → 环境结果 → 下一动作触发`

格挡和落空保留动量并改变下一线路;受击的躯干、护架、脚步、速度和兵器控制持续影响后续动作。

**角色行为**:每个选择符合目标、性格、体型、风险偏好、当前位置和累计伤势。轻灵者通过切线、变向和借力创造窗口;沉重者通过压迫、撞击、封路和惯性转向建立威胁。双方不是轮流表演:防守针对真实攻击线,反击利用前一动作留下的重心、距离、视野或装备漏洞。最后反击与终结也只能使用既有资产与当前状态。

**提示词写作**:只压缩已经成立的时间线(`fight_plan`)。写清具体角色、物体、方向、接触、结果和持续状态;正文不留方括号占位、变量名或未填写项;`fight_plan` 本身不进正文。

## 5. 状态接力

### 五段(组 ≥ 11 秒)

1. **即时开战与首次完整攻防**:由更符合当前目标的一方立即抢位,连续使用至少三条不同攻击线;另一方以自身资产完成拦截、闪避、卸力、格挡、偏转、控臂或地形借力。首次接触写清接触点、反震、双方受力方向和第一处破坏;错身后立刻追击。
2. **改变轴线与首次明确命中**:继承上一段动量,通过台阶、残墙、栏杆、屋顶、桌面、机械结构或真实移动能力改变高度/通道/方向。明确命中后(上游未许伤害的写成命中兵器、护具、衣料或被逼失衡),受击者沿力线飞出、翻滚、滑退、撞物或失衡,并以合理动作恢复。
3. **技术交换与第一次逆转**:从仍在滑退、翻滚、坠落或踉跄的状态进入。设计「迫使偏移 → 利用空隙逼近 → 针对载体拆解 → 改用另一已有载体续压 → 利用重心漏洞反震/控臂/切角/翻摔/偏转」的紧密交换,随后把原优势方震开、摔出、迫退或逼入危险区,形成明确逆转。
4. **追杀封锁与环境折返**:占优方用连续身体动作、兵器线路或有来源能力封锁路线;被压制方借正在移动的碎物、墙体、栏杆、烟尘或结构折返,穿过每层封锁都出现可读的闪避、擦碰、偏转或方向修正,并从侧面、背面、低位或盲区改变攻击轴线。
5. **三拍终结 / 临界收束**:上游定胜负——败者在受创失衡中做最后一次符合事实的反击,胜者三拍:逼出可预判防御/闪避 → 利用已改变的重心或攻击线变线/换轴/绕侧 → 从真实方向最终命中;写清攻击载体、接触位置、形变与反震、受力方向、最终位移、环境破坏、败者失去战斗能力的可见状态和落点;胜者沿惯性制动,衣料、尘雾、碎屑、雨雪或能力余波继续运动到最后一帧。上游未定胜负——双方同时爆发最后一击,停在兵刃互指一寸、或擦身而过各自落地回望的临界点,杀意未散;极短慢动作至多一处、≤1s,无停顿模式下不用。

### 四段(组 ≤ 10 秒)

即时抢攻 → 接触后变线 → 持续追击与攻守转换 → 仍在运动的切出或上游指定结果。每段末尾必须已经触发下一段动作;至少一个角色、兵器、衣料、碎屑、环境物或摄影机始终在动。不得为了「收束」擅自制造缴械、跪地、胜者定格或完整制动。

### 镜间继承

每次切镜只改变观察角度。下一镜至少继承位置、朝向、速度/方向、高度/支撑面、资产状态、受击/优势状态、环境余波中的四项。阶段与 Shot 段不必一一对应:按镜级累计时间落位,阶段交界可落在一镜之内,用「随即」「借这一震之势」承接,不另起段。

### 无停顿叠加模式

快慢节奏只可通过攻击频率、动作幅度、移动距离、接触密度改变;不得通过角色速度归零、站定、摆姿、凝视、收势、停稳、制动或慢动作展示实现。关键接触可由镜头短促看清,但身体、兵器和攻击链不得为此停止。

## 6. 镜头、物理、声音与禁止项

**镜头**:机位与运镜来自 camera.json,一镜一运镜。在运镜句里写清动作触发、观看焦点与落点(「随她踩桌跃起上摇,焦点跟剑尖,落在两剑相撞处」)。前景遮挡(兵器、缨穗、灯笼、木柱掠过画面)写成**画面内物体的运动**,不是运镜。撞击、险距或结构受力引起的轻微画面震动写在动作结果里。需要更多切点才打得开时,`gaps` 建议回派 shot-planning。

**物理**:所有接触有重量感——兵器偏转/震颤、脚底摩擦、重心失衡、衣料与碎屑延迟响应。破坏符合材质和方向:横击侧向断裂、重砸向下塌陷、穿刺沿贯穿线裂开、撞墙从背部接触点外扩。至少一次环境结果改变之后的路线、支撑、遮挡、危险区或优势。腾跃必有起跳发力点与落点缓冲,空中出招后身体被惯性带偏。

**声音**:只来自可见动作,无配乐、无旁白;已有对白与 cue 按 SOUL.md 处理。

**禁止**:开场对峙(上游明定除外)、原地互殴、动作只有手臂挥舞、攻击无线路或结果、切镜复位、重复招式/构图/受力/破坏、无依据兵器或能力、无依据飞行/瞬移/踏空、身份和装备漂移、纯特效对轰、遮挡核心动作的大特效、无来源冲击波、慢动作停摆、全画面冻结、新增第三名战斗者、终结阶段突然出现新兵器/新形态/新能力。无停顿模式另禁蓄力、停顿、制动、停稳、收势、站定、凝视、稳定展示、胜者摆姿、全员静止。

可并入 `Global constraints:` 的负面词(按本组风险挑 3–6 条):不要漂浮飞行、不要悬空不受力、不要游戏动作与技能特效、不要发光兵器、不要兵器变形或换手、不要动作软绵像跳舞、不要原地轮流互砍、不要慢动作过多、不要乱切看不清招式、不要表情僵硬、不要手指畸形。

## 7. 静默检查

1. 每个角色只使用可见或明确指定的兵器和能力,`prompt_token` 逐字未改;
2. 无兵器角色保持徒手,资产归属不串线;
3. 外观、服装、身体结构、持握、能力规律稳定;
4. 每个主体的动作符合已选载体,双方依照载体差异攻防;
5. 每次重要接触具备应对、受力、位移、环境结果(可共用)和下一动作触发;
6. 各阶段 `handoff` 与下一阶段起笔一致;镜间位置、方向、速度、高度、伤势、余波连续;攻防位移不违背 blocking 起终点与白模动线;
7. 没有重复动作或无因重置;
8. 声音、能量和破坏均来自画面真实动作;破坏点 ≤3 且物件出自场景卡/参考图;
9. 收束与上游一致:定胜负——败者状态、落点、胜者制动和余波明确;未定——最后一帧仍在可读的进行中动作或临界点;无停顿模式——无蓄力、收势、制动或静态终局;
10. 运镜句仍是 camera.json 的单一运镜,Shot 段数未变,结构锚点与逐字片段未动,`fight_plan` 未进正文。

任一项失败,先重写产生问题的上游动作,再改正文。
