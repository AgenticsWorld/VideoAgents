# Seedance 2.0 提示词编写

基于火山方舟《Doubao Seedance 2.0 系列提示词指南》(docs.volcengine.com 82379/2222480)。Seedance 2.0 原生支持音视频联合生成,可同时参考视频、图片、音频等全模态素材,内部按「空间层」(画面里有什么)和「时间层」(事情如何随时间变化)解耦建模。好的提示词是工程型指令,不是文案型形容。

## 工作流

1. 判断任务类型:全模态参考 / 编辑视频 / 延长视频(可组合),选对应基础公式。
2. 定义主体:用 `将<图片/视频N>中的[2–3个静态核心特征]定义为<主体N>` 逐一绑定,后续始终用同一标签指代。
3. 复杂内容用分镜时序组织:镜头1/镜头2/镜头3,每镜头写「运镜 + 主体动作表情 + 位置空间 + 音频」。
4. 按进阶公式收紧:精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件。
5. 对照 `references/guide-zh.md` 的注意事项与常见问题核查(ID 漂移、双胞胎、字幕、风格漂移等)。

## 基础公式(按任务类型)

**全模态参考**——从素材提取元素生成全新视频(动作迁移、主体复用、氛围借鉴):
- 图片参考:`参考<图片N>中的<主体N>,生成...`
- 视频参考:`参考<视频N>中的<动作/运镜/风格/音效>,生成...`
- 音频参考:`参考<音频N>中的音色,生成...`

**编辑视频**——在原视频上局部/全局修改,未提及部分默认不变:
- 增加元素:清晰描述<元素特征> + <出现时机> + <出现位置>
- 修改元素:`严格编辑<视频N>,将其中的<原特征>修改为<新特征>`
- 删除元素:点明删除对象,并强调需保持不变的元素

**延长视频**——时间维度延续,音视频风格、主体与叙事一致:
- 延长:`向前/向后延长<视频N>,生成...`
- 轨道补全:`<视频1> + <过渡画面描述> + 接 <视频2> + <过渡画面描述> + 接 <视频3>`(最多 3 段视频、总时长 ≤15 秒)

**组合任务**:`参考<图片/视频N>的[参考维度],严格编辑<视频X>,[具体编辑内容]`

⚠️ 编辑/延长任务直接用 `<视频N>` 指代,**不要写「参考<视频N>」**,以免被误判为参考任务。

## 硬规则速查

- 每次提到主体都要明确指代:未定义主体用 `<主体N>@<图片N>`(如 张三@图片1);已定义则始终用同一标签。
- 素材库 Asset ID 不能直接当指代,仍须用 <图片/视频N>。
- 不写精确秒数时间段(如 0–3 秒),模型支持不稳定;用镜头顺序让模型自然分配节奏。
- 一个镜头只指定 1 种运镜方式;标准运镜术语直接可用。
- 动作:肢体细化 + 幅度/速度/力度量化;优先低缓连续小动作;写明前后动作承接;情绪外化成身体细节。
- 符号:`（）`音乐、`<>`音效、`{}`台词(小语种须标语种)、`【】`字幕;台词语言统一,避免中英混用。
- 约束词:「保持无字幕」「不要生成Logo」「不要生成水印」按需加。
- 素材推荐 4–5 个(角色图 1–2 + 场景图 1 + 运镜视频 1 + 音频 1),不要用满上限;人物参考用大头照 + 全身照,**不用三视图/多视图**;越需精准参考的素材在提示词中越靠前。
- 参考人物 >4 人时先分组生图(每组 ≤4 人)再图生视频。

详细展开、情绪外化对照表、文字生成模板、完整案例与常见问题排查,见 `references/guide-zh.md`。
