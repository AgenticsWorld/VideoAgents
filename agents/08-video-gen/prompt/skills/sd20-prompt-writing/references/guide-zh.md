# Doubao Seedance 2.0 系列提示词指南(整理版)

来源:火山方舟官方文档《Doubao Seedance 2.0 系列提示词指南》(https://docs.volcengine.com/docs/82379/2222480,最近更新 2026-08)。本文件为供 Agent 使用的文字整理版,保留原文公式、规则与示例提示词。

Seedance 2.0 系列模型原生支持音频与视频联合生成,支持同时参考视频、图片、音频等全模态素材,能精准锁定人物样貌、动作特效、视觉风格、配音音色等特征。

---

## 一、基础公式

参考生视频细分为三类任务:全模态参考、编辑视频、延长视频。按任务类型选公式。

### 1. 全模态参考

从素材中提取部分元素(主体、风格、场景、音效),生成一个全新视频。
适用场景:动作迁移、主体复用、氛围借鉴等。

推荐句式:
- 图片参考:`参考<图片N>中的<主体N>,生成...`
- 视频参考:`参考<视频N>中的<动作/运镜/风格/音效>,生成...`
- 音频参考:`参考<音频N>中的音色,生成...`

### 2. 编辑视频

在原视频基础上进行局部或全局修改。未提及的部分,默认保持不变。
适用场景:局部替换、主体抹除、属性修改等。

推荐句式:
- 增加元素:清晰描述 `<元素特征> + <出现时机> + <出现位置>`
- 修改元素:`严格编辑<视频N>,将其中的<原特征>修改为<新特征>`
- 删除元素:点明需要删除的元素;对于保持不变的元素,在提示词中加以强调,表现更佳

### 3. 延长视频

在时间维度上延续原视频,要求音视频风格、主体与叙事保持一致。
适用场景:续写剧情、延展动作、补全片段等。

推荐句式:
- 延长视频:`向前/向后延长<视频N>,生成...`
- 轨道补全:`<视频1> + <过渡画面描述> + 接 <视频2> + <过渡画面描述> + 接 <视频3>`

**注意**:编辑/延长视频任务,直接使用 `<视频N>` 指代视频,请勿使用「参考<视频N>」,以免被误判为参考任务。

**轨道补齐限制**:最多支持 3 段视频输入,总时长不得超过 15 秒;生成时自动截取首尾视频的衔接部分,仅保留必要片段参与合成。

**视频延长说明**:模型将自动截取衔接部分进行合成,输入视频原有片段不会重复生成。

### 4. 组合任务

三类任务支持组合使用(参考某个素材、编辑另一个素材):

`参考<图片/视频N>的[参考维度],严格编辑<视频X>,[具体编辑内容]`

## 二、进阶公式

Seedance 2.0 本质是一个全模态 AI 导演:同时读取文字提示词、图片、视频、音频,并在内部拆成「空间层」(画面里有什么)和「时间层」(事情如何随时间变化)两个维度来理解和生成画面。好的提示词不是「文案型形容」,而是「工程型指令」:谁、在什么场景、做什么动作、镜头如何运动、按怎样的时间顺序发生。

**进阶公式:精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件**

先锁定「谁」在「干什么」,再交代「在哪」「什么氛围」,然后告诉模型「怎么拍」,最后用风格、画质和约束条件收紧结果。

### 2.1 定义主体

一张图片中往往存在多个主体(人物、道具、场景等),必须明确定义才能精准引用。

推荐句式:`将<图片/视频N>中的[主体核心特征]定义为<主体N>`

核心特征要求:使用 2–3 个清晰、稳定的**静态特征**(服饰、发型、外观、类别)描述,确保唯一可识别。

示例:
- 将图片1中穿红色连衣裙、戴草帽的女人定义为主体1
- 将图片1中穿红色连衣裙、戴草帽的女人定义为张红

**多主体分别定义**,标签唯一稳定,后续持续使用对应标签:

推荐句式:`将<图片/视频N>中的[主体1核心特征]定义为<主体1>,将<图片/视频N>中的[主体2核心特征]定义为<主体2>...`

示例:将视频1中的高个子男人定义为警察,将另一个矮个子男人定义为小偷。场景设定为拥挤的白天集市,阳光明媚,周围有许多水果摊位和密集的行人,充满市井生活气息。小偷在拥挤的集市人群中惊慌失措地向前狂奔,警察在后方紧随其后全速追赶,两人快速穿梭在各个摊位之间。手持镜头向前快速跟拍,画面带有轻微真实的晃动感,营造追逐的紧张氛围。

**多素材同一主体统一绑定**:

推荐句式:`将图片1中的[...]、图片2中的[...]定义为<主体N>`

注意事项:
- 每次涉及主体都要明确指代,避免省略。未定义主体的简单场景,每次都用 `<主体N>@<图片N>` 强调绑定关系(例:张三@图片1);已定义主体的场景,每次都用同一标签。
- 使用素材库(Asset ID)时,仍须用 <图片/视频N> 指代主体;模型无法直接关联 Asset ID 与参考内容,不得以 Asset ID 替代。
- 描述尽量简洁,避免冗余,避免语义冲突(同一主体出现矛盾特征)。
- 空间关系建议优先通过参考图表达,减少复杂文字描述。

### 2.2 使用分镜时序

模型内部建模空间与时间解耦,复杂视频提示词最理想的形态是**时间轴化分镜**:把视频拆成几个分镜,按事件发生顺序动态描述每个分镜:谁 + 在哪 + 做什么 + 镜头怎么动。

反面案例:「男人在街头紧张地奔跑,画面很有电影感。」

正面案例:
- 镜头 1:街巷侧拍,男人缓慢起跑,带有急促的呼吸感。
- 镜头 2:男人撞翻水果摊,镜头快速摇动并给到男人惊恐的特写。
- 镜头 3:男人翻过矮墙消失,镜头缓慢拉远定格在空荡的街道。

具体规则:
- 使用「镜头1、镜头2、镜头3」标识,按事件发生顺序(先主后次)组织内容。不强制限制每段时长,优先让模型根据剧情自然生成节奏。
- **模型对精确时间(如 0–3 秒)的支持不稳定,强行限制时长可能导致生成结果异常。**
- 每个镜头推荐按以下逻辑组织:
  1. 运镜或镜头切换方式:如「全景缓慢推近」「固定机位」「镜头切至…」
  2. 主体动作与表情:核心角色/物体的关键动作、神态变化
  3. 位置或空间变化:主体所处的场景、位置或空间关系
  4. 音频信息:对应镜头的音效、人声或背景音乐

### 2.3 动作描述要求

1. **肢体细化 + 程度量化**:动作具体到手、腿、头部、肩背等部位,补充幅度、速度、力度。示例:缓慢抬手、快速转头、用力蹬地、微微低头。
2. **优先低缓连续小动作**:优先缓慢、轻柔、连贯的细微动作,规避狂奔、大跳、剧烈翻滚等高爆发大动态动作。示例:缓慢行走、轻轻抬手、微微低头、顺势坐下。
3. **补充动作过渡衔接**:写明前后动作的惯性与承接关系。示例:借着转身惯性顺势抬手、从停顿状态自然过渡到举手。
4. **情绪具象外化表达**:用具体身体细节表现情绪,替代「很悲伤」「非常愤怒」等抽象词。

情绪外化对照表:

| 抽象情绪 | 外化为动作与细节 |
|---|---|
| 愤怒 | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀般锐利、从牙缝里挤出话语 |
| 紧张/焦虑 | 频繁地看手表、手指不停敲击桌面、呼吸急促、眼神闪躲、无意识地啃咬指甲 |
| 喜悦 | 嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快、下意识地哼起小曲、忍不住原地转个圈 |
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识地攥紧衣角、泪水在眼眶里打转但没有落下 |
| 释然 | 长长地舒了一口气、紧绷的肩膀完全放松下来、脸上露出久违的淡淡的微笑、抬头望向远方 |

### 2.4 运镜写法

模型对运镜词理解力很强,直接使用标准运镜术语即可,如「中景、特写、全景、缓慢推镜、平稳横移、固定镜头」。

**注意:一个镜头里尽量只指定 1 种运镜方式**,不要同时要求推拉摇移,会增加画面不稳定性。

### 2.5 画质、风格与约束词

1. **画质**:定义清晰度、细节纹理与光影质感。示例:高清,细节丰富,电影质感,色彩自然,光影柔和。
2. **风格**:设定整体美术画风与视觉调性。示例:赛博朋克冷蓝紫色调、复古胶片、日系清新。
3. **约束词**(重要,规避画面瑕疵、畸形崩坏及不合理元素):
   - 避免生成字幕:「保持无字幕」「避免生成任何文字或字幕」
   - 避免生成 Logo:「不要生成Logo」
   - 避免生成水印:「不要生成水印」

## 三、其他技巧

### 3.1 文字生成

模型支持生成常用文字,能根据情境自动匹配风格与颜色,也支持指定文字的颜色、风格、出现方式、出现时机、出现位置。**优先使用常用字,避免生僻字与特殊符号。** 支持广告语、字幕、气泡等场景。

模板:`「文字内容」+「出现时机」+「出现位置」+「出现方式」,「文字特征(颜色、风格)」`

- 字幕模板:`画面底部出现字幕,字幕内容为"……",字幕需与音频节奏完全同步。`
- 气泡台词模板:`「角色」说:"……",角色说话时周围出现气泡,气泡里写着台词。`
- 广告语案例:手绘漫画风格,三个人围坐在一起吃图片1中的炸鸡,气氛友好愉悦,后画面逐渐模糊,画面中部显示文字"快乐尽在 Seedance"。

若对文字表现效果要求严格,可用 Logo 参考图(见多图参考案例)。

### 3.2 视频延长 vs 分段拼接

- **连续长镜头(视频延长)**:适用单一场景内的「文戏」,如长对话、情绪递进、单一路径移动,实现沉浸式一镜到底效果。
- **场景/动作转折(分段拼接)**:适用剧情转折或复杂快速的「武戏」,如追逐、打斗、蒙太奇,独立生成片段再剪辑组合,保证节奏与视觉冲击力。
- 实际制作通常两者结合:先用延长生成连贯对话,再拼接空镜或转场片段。

### 3.3 素材配置策略

素材分四种功能角色:
1. 角色锚定:锁定角色外观
2. 场景定调:锁定环境与风格
3. 运镜参考:锁定镜头语言与动作节奏
4. 节奏氛围:用音频控制情绪、音色

**推荐配置(总计 4–5 个素材)**:角色图 1–2 张(面部特写/全身)+ 场景图 1 张 + 运镜视频 1 段 + 音频 1 段。

不建议用满素材上限:过多素材导致模型难以判断特征优先级,易出现风格冲突、主体识别模糊、生成效果偏离预期。

## 四、注意事项

### 语言规范

台词语言需统一,避免中英文混用(专有名词除外)。

### 特殊字符规范

| 信息类型 | 符号 | 示例 |
|---|---|---|
| 音乐 | `（）` | （背景中播放着快节奏的摇滚乐） |
| 音效 | `<>` | <远处传来狗叫声> |
| 台词 | `{}` | {你好,世界}。小语种(非中英文)需标注语种,如:用日语说道{こんにちは} |
| 字幕 | `【】` | 【第一章:启程】 |

## 五、常见问题排查

### 5.1 人物 ID 漂移

现象:角色形象与参考图不一致,或视频中途「换脸」,甚至撞脸明星被审核拦截。

根因:人脸参考图有效性不足——参考图混用(人脸与全身/姿态/服装/细节合并在一张图)、人脸占比过小(特征提取权重不够)。

解决:
1. 准备**人脸特写图**:在全身照之外,额外准备一张只含角色头部的大头照(仅保留面部,无表情最佳,尽量减少肩颈、背景干扰)。
2. 提示词中主体定义清晰:`<主体1>的面部特征参考图片1(大头照),妆造参考图片2(全身照)`。
3. **重要素材前置**:越需要精准参考的素材,放在提示词中越靠前的位置。

注意:人物参考用大头照 + 全身照即可,**不建议使用人物多视图**——多视图包含同一人物不同角度,模型易识别为多个不同主体,反而加剧 ID 漂移。

### 5.2 视频中包含字幕

无法 100% 避免,只能降低概率:
1. 提示词加约束指令:「保持无字幕」「避免生成任何文字或字幕」。
2. 参考图片/视频中的非必要文字,先用工具去除(如 Seedream/Seedance 编辑能力)再作输入。
3. 业务允许时优先横屏生成(横屏出字幕概率明显低于竖屏),后续剪辑裁竖屏。

### 5.3 视频中有 Logo / 水印

提示词加约束指令:「不要生成水印」「不要生成Logo」。

### 5.4 风格漂移

现象:期望 2D/3D 动漫风格,但参考图偏写实且提示词未强调风格,生成结果漂移成真人写实。

解决:提示词加明确风格约束词(如「2D日漫风格」「3D国风漫画」);需更精准控制时,先把参考图转为目标风格再生视频。

### 5.5 延长视频衔接处跳变

现象:延长生成的新视频与原视频拼接时,衔接处画面跳变、回退。

解决(后期剪辑修补,对齐关键帧):
1. 导入剪映或其他剪辑软件。
2. 第一个衔接处:前一段视频末尾删减 6 帧,后一段视频开头删减 1 帧。
3. 所有拼接点重复以上操作,导出检查流畅度。
4. 帧对齐后仍可能有细微跳变:建议续写生成时以转场切镜时刻结尾,下一段以切镜后的新场景为起始。

### 5.6 双胞胎问题

现象:画面人物较多且传入人物三视图作参考时,同一画面出现两个完全相同的人物。

根因:人物主体定义不清晰;三视图/多视图易造成人物识别混淆。

解决(无法 100% 避免,降低概率):
1. 明确人物主体关联:清晰定义每个角色与参考图的对应关系,人物名后标注参考图并保持格式统一。示例:张三(对应图片 1)将绿色存折扔向站立的李四(对应图片 2)。
2. 添加全局约束指令(提示词末尾):`视频全程禁止出现外形、着装、配饰完全一致的人物,禁止生成同款分身、双胞胎效果,同一画面中仅保留单个对应人物,不出现人物重复复刻`。
3. 优化参考素材:优先单人独立照片,不用三视图/多视图。
4. 精简提示词:勿直接把完整剧本当提示词,冗余文案造成理解混乱。

### 5.7 视频延长画质劣化

现象:用模型生成的视频作输入续写时画质劣化,多次续写叠加劣化,人脸区域易出现斑驳色块。

解决:
1. 先将原始视频用 Seedance 2.0 转为白模视频,再作续写输入。参考提示词:`将视频转为白色 3D 模型,人物统一为纯白 3D 模型,无色彩、无纹理、无阴影,纯白背景,结构稳定、运动流畅。`
2. 优先选用高清图片作参考素材。
3. 合理控制续写次数,避免多次叠加。

### 5.8 特效效果不符合预期

现象:纯文字描述特效易走样(如「数字2999以倒计时动画出场」生成无序跳变)。

解决:用**参考视频**定义特效,让模型精准理解特效形态与运动逻辑。示例:`数字"2999"出场方式参考视频1`。

### 5.9 参考人物过多

现象:参考人物超过 4 人时输出稳定性下降,可能少人、多人或人物重复(实测输入 8 个参考角色,输出出现 9 人)。

解决:
1. 分步生成图片:人物分组,每组图片中人物 ≤4 人(如 6 人分 2 组各 3 人,分别生成图片)。
2. 再用分组图片作参考素材生成最终视频。

### 5.10 视频结尾有噪音

现象:含旁白的视频片尾易出现突兀咔哒声、截断杂音。

解决:重新生成,或用剪映等工具对片尾音轨做音量包络线淡出(末尾音量关键点拉至 0 形成向下斜坡)。

### 5.11 中文发音不准

现象:多音字、生僻字、形近字易读错。

解决:替换为发音一致的常用同音字(如「螭龙山」改写为「吃龙山」)。仅为优化手段,无法完全规避。

### 5.12 音色参考不准

现象:参考音频指定音色时,生成音色与参考存在明显偏差。

解决:
1. 提示词补充细致的音色特征描述,如:`使用@音频1低厚温润带细碎颗粒感中年男声的音色说`。
2. 保持视频台词风格与参考音频的语气、表述风格相近。

### 图片参考

支持主体多视角参考、场景图、分镜图等多图参考。**如对图片顺序有要求应按顺序上传**,提示词中用图片1、图片2……准确指代。
